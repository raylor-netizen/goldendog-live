# Showcase checklist

- [ ] `lb build` produces hybrid ISO
- [ ] ISO copied to Lexar Ventoy (`/dev/sdb1`)
- [ ] Boots to Plasma (not installer-only)
- [ ] GoldenDog branding packages visible
- [ ] Optional: keep official netinst on same stick for A/B

## RAM note

Upstream prefers install-only partly because live uses a lot of RAM. Treat **4 GiB+** as a practical floor for this Plasma live image.
